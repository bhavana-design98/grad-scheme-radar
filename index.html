How it stays fresh. A script runs every morning, opens every employer page in this list, and reads whether applications are still open. Anything marked closed, expired or removed drops out of the default view. A separate search pass looks for new schemes and adds them with a purple "new" tag.

Trust, but verify. Some employer pages are built so that a script cannot read them. Those show as "not confirmed open" until the daily hand-check reaches them. The same label covers employers that have not posted their 2027 scheme yet. Always confirm the deadline on the employer's page before you plan around it.
